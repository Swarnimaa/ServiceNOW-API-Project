OPTIMIZATIONS - 

Partitioning on Business Date
Large Gold fact tables were partitioned by: YEAR

Applied Z-Ordering
We optimized Delta tables using:
OPTIMIZE gold_patient_visits
ZORDER BY (patient_id, hospital_id)


Reduced Power BI Load Time

We:

removed unnecessary technical columns
exposed only business-required fields
pre-calculated KPIs

Examples:

average LOS (length of stay)
readmission %
claim approval %
appointment no-show %

👉 Reduced heavy DAX calculations in Power BI.



Small File Optimization

Because streaming/microbatch jobs created many tiny files:
we scheduled:

OPTIMIZE gold_claims
VACUUM gold_claims



Caching Frequently Accessed Tables

For high-usage KPI datasets:

CACHE TABLE gold_hospital_kpis



Data Quality Checks Before Gold Publish

We added checks for:

duplicate claim IDs
null patient IDs
invalid discharge dates
negative billing amounts

Only validated records moved to Gold.
